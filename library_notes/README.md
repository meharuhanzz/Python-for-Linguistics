# Library Notes

Short, beginner-facing notes on every tool used across the 5-day tutorial. Each note
covers two things separately, on purpose:

1. **The concept** — what problem this tool exists to solve, in plain language, before
   any code.
2. **Basic usage** — install command, a minimal working snippet, and what each line
   does.

Read the relevant note *before* the day that introduces it, or use it as a reference
while working through an experiment script.

| Note | Library / tool | First used in |
|---|---|---|
| [00_python_stdlib_re_unicodedata.md](00_python_stdlib_re_unicodedata.md) | Python standard library: `re`, `unicodedata` | Day 1 |
| [01_nltk.md](01_nltk.md) | NLTK | Day 2 |
| [02_pandas.md](02_pandas.md) | pandas | Day 2 |
| [03_spacy.md](03_spacy.md) | spaCy | Day 3 |
| [04_huggingface_tokenizers_transformers.md](04_huggingface_tokenizers_transformers.md) | Hugging Face `tokenizers` / `transformers` | Day 3 |
| [05_gensim.md](05_gensim.md) | Gensim (Word2Vec) | Day 4 |
| [06_sentence_transformers.md](06_sentence_transformers.md) | `sentence-transformers` (contextual embeddings) | Day 4 |
| [07_mlmorph_fst_morphology.md](07_mlmorph_fst_morphology.md) | `mlmorph` (FST-based Malayalam morphology) | Day 4 |

These notes deliberately don't repeat what the experiment scripts already show step
by step — they give the conceptual grounding and a tiny standalone snippet so you're
not learning the concept and reading a 100-line experiment script at the same time.
